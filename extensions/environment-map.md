## Поток — в одну сторону

Kai (У1/У2) — спутники захвата → очередь (iwe-kai) → Клод (ПК) → DS-notes.
Симметричного merge памяти нет. Память Kai локальна и разная; объединение — только осознанно Клодом.

## Ключевые правила

- Устройства не пишут в DS-notes / DS-strategy.
- Клод не пишет в u1-plan/ и u2-phone/ без задачи (это зоны захвата).
- Секреты никогда не в git: .exocortex.env chmod 600, ключи в ~/.secrets/.
- Решения → DS-strategy; правила устройств → GOVERNANCE.md (iwe-kai). DS-strategy выше по авторитету; касающееся устройств решение обязано отразиться в GOVERNANCE (контур VIII).
